## BBender's questions: recommendations for Claude

- **Q1 (ambiguous audit: manual or provisional?): keep it manual.** A wrong "given" is the costly error: it drops the
  player's mark, takes the check out of the in-logic list and shows its reward in spoiler-free mode, and the player has
  no way to override it. A manual gift costs one click. The audit left no case ambiguous, so nothing changes now.
- **Q2 (is the D8 exact-version gate too strict?): keep it exact for now.** The dump test certifies only the installed
  version's patched flows; an older seed was patched by code nothing checked against these flags, and the fallback is
  today's behaviour (marks) plus a one-line note, so strictness loses nothing that works today. Relax it only with a
  per-entry "valid since" version once entries are accepted. (A dev checkout reports the same version as the release
  it follows, so seeds from 0.2.5 read with this branch get the reads, correctly: output is identical.)
- **Q3 (D4 vs tracker-in-logic D8/4.5): D4 stands.** An unplayed flag that reads "not given" may be the wrong one, and
  dropping the mark would lose what only the player knows; once an entry is accepted it follows D8 exactly. The note is
  in `plans/tracker-in-logic.md` D8 and 4.5 (`9c16dc0`); drop that commit if Claude decides otherwise.
